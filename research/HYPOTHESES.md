# Falsifiable hypotheses

H1. Identical recorded inputs and engine version reproduce the same discrete simulation event sequence and declared state hashes within a predeclared floating-point tolerance.

H2. Channels explicitly wired to browser sensor summaries respond to those summaries, while unrelated channels remain within expected coupling bounds.

H3. Changing APOD/USGS context in a recorded deterministic seed changes procedural output reproducibly; this is a software generation property, not external physical causation.

H4. Memory Echo export/import preserves predeclared simulation invariants such as world seed, event hash and selected state checkpoints.

H5. Any future predictive claim using live sensor/external context must beat shuffled/time-shifted and matched classical controls on held-out data before its evidence label changes.
