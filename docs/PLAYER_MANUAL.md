# SIM EARTH 7.08 — Player Manual

## 1. Start

Open `standalone/SIM_EARTH_7_08_REALITY_BODY.html` or the installed PWA and select **INITIATE SIM EARTH 7.08**. Sensor permissions are optional. Denying a sensor does not stop the core procedural simulation; it only removes that live input.

When WebGL2 is available, Surface mode uses the 7.08 Reality Body. If WebGL2 is unavailable, the prior Canvas renderer remains the fallback.

## 2. Your viewing layers

**Surface** is planetary traversal. Press `V` on desktop or `VIEW` on mobile to switch between first-person helmet view and Luna's third-person field body.

**Orbit** is the planetary observation/navigation layer.

**Reality Lens** uses available local camera/environment signals as an input surface while preserving the simulation HUD. It is not a live remote planetary camera.

## 3. Luna // field explorer

In third person, Luna appears as a lightweight procedural EVA explorer with helmet, visor, environmental suit, backpack and suit illumination. The character is generated by the one-file WebGL engine rather than loaded from an external model.

## 4. LUNA-ARC

The LUNA-ARC survey vessel spawns near the local world entry point.

### Board / exit

- Desktop: `F`
- Mobile: `SHIP`

Walk near the vessel before boarding. The game refuses an exit while the vessel is too high above terrain.

### Flight

- `W` / `S` or mobile stick — forward/reverse thrust
- `A` / `D` or arrows — yaw
- `Shift` / `SPRINT` — high-speed thrust
- `Space` / `ASCEND` — climb
- `Ctrl` / `DESCEND` — descend

The HUD reports height above ground level while flying.

## 5. Surface controls

- `WASD` / virtual stick — move
- Mouse / drag — look
- `Shift` / `SPRINT` — sprint
- `Space` / `JUMP` — jump
- `E` / `SCAN` — scan
- `V` / `VIEW` — first/third person
- `F` / `SHIP` — board/exit vessel
- `H` — HUD/control panel
- `G` — orbit/surface
- `R` — Reality Lens
- `M` — audio
- `T` — time warp

## 6. Worlds

Known reference worlds ship with anchored values. New named planets are generated deterministically: the same name maps back to the same seed and local persistent history. This is procedural simulation, not a live telescope or satellite feed.

## 7. Growth and persistence

World state evolves as you explore. Scans, outposts, seeded biospheres, anomalies, storms and time spent on a world feed the persistent local ledger. Browser storage lets the universe remember between sessions on the same device/browser profile.

## 8. Command deck

Try:

`goto Mars`, `fold Europa`, `create Aurora-9`, `seed life`, `outpost`, `storm`, `anomaly`, `scan`, `orbit`, `surface`, `reality`, `day`, `night`, `time`.

## 9. Sensors

Microphone input is summarized into spectral bands. Camera frames can be sampled for luminance and motion. Geolocation/orientation/motion are used only when the browser/device exposes them and permission is granted. The canonical build does not require a cloud account.

## 10. Save/export

World history is local. Use the in-engine ledger/state export tools for a portable record. Clearing browser/site data can erase locally persistent worlds.

## 11. Performance

Reality Body automatically lowers some flora work when rendering becomes expensive and caps device pixel ratio. Mobile uses a smaller terrain grid than desktop. If a device does not support WebGL2, SIM EARTH falls back to the Canvas surface renderer instead of refusing to run.

## 12. What this is — and is not

SIM EARTH 7.08 is a game/research visualization and procedural universe engine. Its worlds, Luna and LUNA-ARC are simulated. It is not a survey-derived digital twin, a medical or consciousness diagnostic, or a physical control system for Earth/remote planets.
