# Lineage

This focused repository preserves the universe-engine lineage rather than flattening it into one rewritten story.

1. **SIM EARTH 7.07 / Genesis Engine / Alien Control Center** — historical browser ancestry with event bus, Three.js procedural systems, sensors, NASA/USGS feeds, audio reactivity, adaptive intentions, Particlizer and Memory Echo experiments.
2. **Universe Engine Ultimate** — reconstructed single-file playable engine with unified runtime, deterministic mechanics, persistent worlds, multiple view modes, mobile controls and the 12D→42D→54D state path.
3. **Native Python/C++ rebuild** — explicit separation between external network ingestion and an authoritative C++ fixed-step simulation core.

The archive exists so contributors can inspect actual ancestry and compare architecture changes.
