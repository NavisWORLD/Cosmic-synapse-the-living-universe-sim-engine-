# Scientific boundaries

## Supported engineering statements

This repository implements procedural simulation, game mechanics, sensor summaries, public-data context ingestion, persistence and adaptive software state.

## Not established by this repository

- consciousness or sentience;
- extra physical dimensions;
- a new fundamental law of physics;
- quantum advantage;
- precognition;
- causal astronomical/geophysical influence on local physical reality;
- predictive skill merely because a live external variable enters a seed.

## External data

NASA/USGS data are observations used as software inputs. Any resulting visual or game response is an authored mapping unless a separate experiment demonstrates something more.

## State channel names

Names such as `quantum_entropy`, `entanglement`, `singularity`, `valence` or `arousal` identify software features/control proxies in this simulation unless a specific validated measurement protocol says otherwise.
