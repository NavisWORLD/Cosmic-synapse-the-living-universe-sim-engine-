# Teacher Guide — Living Universe Engine

## 10-week course

### Week 1 — evidence labels and lineage
Classify implementation, test, hypothesis and metaphor.

### Week 2 — deterministic procedural generation
Reproduce worlds from identical seeds.

### Week 3 — fixed-step simulation
Compare state under different render frame rates.

### Week 4 — multimodal sensors
Inspect compact microphone/camera/location summaries without treating raw media as permanent state.

### Week 5 — CST software-state layers
Perturb inputs and graph 12D, 42D and 54D responses.

### Week 6 — NASA/USGS context
Replay saved external snapshots and distinguish public observation from authored game response.

### Week 7 — world persistence
Build/export world state and event ledgers.

### Week 8 — Memory Echo
Define invariants and compare captured/reloaded simulation artifacts.

### Week 9 — preregistration and controls
Write a test with a primary metric, null, controls and failure criteria before running it.

### Week 10 — replication report
Publish results including failures/nulls, exact software commit and environment.

## Grading

- 30% reproducibility
- 25% engineering correctness
- 20% experimental controls
- 15% documentation
- 10% interpretation discipline
