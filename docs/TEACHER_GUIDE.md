# Teacher Guide — SIM EARTH 7.07

## Purpose
SIM EARTH 7.07 can be used as a creative-computing and systems-thinking lab. It is especially useful for lessons where students need to separate **measurement**, **model**, **simulation**, and **hypothesis**.

## Suggested age bands
- **Grades 5–8:** procedural worlds, ratios, coordinates, ecosystems, cause/effect.
- **Grades 9–12:** vectors, dynamical systems, FFT intuition, state machines, orbital/planetary calculations, reproducibility.
- **College / maker programs:** browser architecture, PWA/native packaging, validation design, computational modeling, human-computer sensing.

## Learning objectives
Students should be able to:
1. distinguish a simulated quantity from a directly measured sensor value;
2. explain why a high-dimensional state vector can be useful without implying extra spacetime dimensions;
3. describe deterministic seeding and reproducibility;
4. identify how audio/camera/location signals are transformed before entering the state engine;
5. compare a physical equation, a normalization, and a heuristic control signal;
6. design a falsifiable experiment around one simulator claim.

## 45-minute lesson — Build a planet, audit a claim
1. **5 min:** open the simulator and choose a world.
2. **10 min:** record gravity, atmosphere, temperature, biosphere, and 12D/54D readouts.
3. **10 min:** create a new named world twice and test deterministic persistence.
4. **10 min:** classify five readouts as sensor-derived, physics-derived, procedural, or heuristic.
5. **10 min:** write one hypothesis and one test that could disconfirm it.

## 90-minute lab — Sound into state
Students enable microphone access (only with institutional policy/consent), generate quiet/speech/music conditions, and record changes in frequency mass, spectral flatness, audio Ψ, and the adaptive state. The goal is **not** to prove a biological or cosmological claim. The goal is to study signal processing and model response.

## Accessibility / special-needs use
- Use the HUD as an optional visual scaffold; it can be hidden when overstimulating.
- Audio permission is optional; the core experience remains usable without it.
- Prefer predictable, short missions and student-selected worlds.
- Avoid interpreting sensor-derived values as diagnoses, emotions, deception detection, or medical measurements.
- Allow movement through keyboard, touch, or observation-only roles in paired activities.

## Assessment prompts
- What is reproducible here, and what is random?
- Which channel is a direct sensor measurement?
- Which channel is a normalized or derived feature?
- Why does naming a 54-element vector “54D” not prove 54 physical dimensions?
- How would you falsify a claim that a state channel improves prediction or adaptation?

## Teacher safety/privacy note
Do not require camera, microphone, or precise location for classroom participation. Obtain consent according to school policy. The canonical engine is designed to function without mandatory sensor permissions.
