# Study Guide

## Questions

1. Why is a fixed simulation step useful for reproducibility?
2. What makes a procedural world deterministic?
3. What is the difference between external measured data and the game's response to it?
4. Why are 12D/42D/54D software vectors not evidence of extra physical dimensions?
5. What must be recorded to replay a universe?
6. What privacy concerns arise from camera, microphone and location inputs?
7. Why are shuffled/time-shifted controls useful when testing sensor-related prediction claims?
8. What would count as a null result for deterministic replay?
9. How does Memory Echo differ from a screenshot?
10. Which renderer effects should remain outside the authoritative simulation state?

## Exercises

- Reproduce the same procedural world from the same seed.
- Change one sensor input and identify exactly which channels move.
- Replay a saved APOD/USGS snapshot offline.
- Deliberately introduce frame-rate-dependent physics, measure the divergence, then fix it.
- Export a world ledger and calculate a canonical hash.
