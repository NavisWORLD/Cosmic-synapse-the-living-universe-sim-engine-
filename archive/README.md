# Historical SIM EARTH ancestry

`SIM_EARTH_7_07_ALIEN_CONTROL_CENTER.html` is preserved losslessly as the browser ancestry of this branch.

It contains overlapping generations of the project: a large Three.js procedural universe, event bus, NASA/USGS manager, sensory input, adaptive intention/scheduling, audio particles, cosmic-web/black-hole/atmosphere experiments, Particlizer and Memory Echo concepts, plus later/fallback layers.

It is preserved for lineage and engineering comparison. New users should start with the Ultimate engine at repository root.
