# Contributing

1. Keep the canonical one-file engine runnable.
2. Do not silently rewrite research claims as established physical facts.
3. Preserve the distinction between sensor measurement, derived physics, procedural state, and hypothesis.
4. Run `npm run verify` before a pull request.
5. Keep native/desktop packaging additive; the canonical standalone file remains the source artifact.
6. New third-party dependencies must include license/provenance information.
7. Never commit secrets or private recordings.

Small focused pull requests are preferred. Explain what changed, why, how it was tested, and whether it affects a research claim.
