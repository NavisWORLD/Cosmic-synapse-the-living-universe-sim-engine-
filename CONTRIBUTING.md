# Contributing

Contributions are welcome.

1. Keep the evidence labels in `NOTICE.md` intact.
2. Do not turn a proposed test into a claimed result without data, environment information, code revision and reproducible analysis.
3. Keep external observations distinct from authored simulation mechanics.
4. Add deterministic tests when changing seed/state code.
5. Never commit API keys, private camera/microphone recordings or precise personal location histories.
6. Preserve historical ancestry rather than rewriting it out of the project.
7. Negative and null results are valid contributions.
