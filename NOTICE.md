# Evidence labels

This repository uses explicit evidence labels:

- **IMPLEMENTED** — code or an artifact exists.
- **SOFTWARE-TESTED** — a stated software execution/check has been completed.
- **DESIGN TARGET** — an architecture is specified but is not yet fully implemented.
- **PROPOSED TEST — NOT YET RUN** — a protocol exists in advance of data.
- **SIMULATION/METAPHOR** — a visual, mathematical or game construct, not a literal physical claim.

A visually convincing simulation is not automatically experimental evidence.
